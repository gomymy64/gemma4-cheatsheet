03Пошаговая инструкция

01

Установи Ollama

Это программа, которая позволит тебе скачивать и запускать открытые нейросети прямо на своём компьютере. Работает в фоне, весит мало.

Открой ollama.com
Нажми кнопку Download
Скачай версию для своей ОС (Windows / Mac / Linux)
Установи и запусти - иконка ламы появится в трее
02

Спроси Claude какую версию Gemma 4 ставить

Если не знаешь потянет ли твоё железо - сделай скриншот характеристик ПК и попроси Claude подобрать версию под твоё железо.

Открой "О системе" (Windows) или "Об этом Mac" (Mac)
Сделай скриншот окна с характеристиками
Открой Claude (claude.ai или Claude Code) и вставь скриншот
💬 Промпт - подбор версии
Вот мое железо, какую версию Gemma 4 от Ollama мне лучше установить?
⚙️ Claude порекомендует версию исходя из твоего RAM и GPU. Обычно это gemma4:e4b (лёгкая, ~9.6 ГБ) или gemma4:27b (мощная, ~16 ГБ).
03

Установи Antigravity и открой терминал

Antigravity - это бесплатная среда разработки от Google где работает Claude Code. Именно в ней будем запускать локальную модель.

Открой antigravity.google
Скачай Antigravity для своей ОС и установи
Запусти Antigravity
Открой терминал внутри Antigravity: Ctrl + ` (тильда)
💡 Подсказка: Не знаком с Antigravity? Смотри полный гайд здесь - разбор Antigravity за 15 минут
04

Скачай Gemma 4 через терминал

Одна команда - и Ollama скачает модель со всеми весами автоматически. Дальше просто ждёшь пока скачаются гигабайты бесплатной нейронки.

⌨️ Команда - скачать модель
ollama pull gemma4:e4b
Вставь команду в терминал и нажми Enter
Жди пока скачается (~9.6 ГБ, 10-15 минут в зависимости от интернета)
Когда появится "success" - модель установлена
💡 Совет: Если нужна другая версия - замени e4b на ту, которую порекомендовал Claude в Шаге 02.
05

Протестируй Gemma 4 в Ollama

Перед интеграцией в Claude Code - убедись что модель работает. Открываешь приложение Ollama и задаёшь любой вопрос.

Открой приложение Ollama (иконка ламы)
Выбери модель gemma4:e4b в списке внизу
Задай тестовый вопрос
💬 Промпт - тест работы модели
Кто был самым высоким человеком из когда-либо живших на земле?
✅ Проверка: Модель должна показать процесс мышления и ответить: "Роберт Уодлоу, рост 8 футов 11 дюймов". Всё сгенерировалось локально - без интернета, без API.

Бонус - тест мультимодальности: Gemma 4 умеет читать картинки. Сделай скриншот чего угодно, вставь в чат Ollama и спроси:

💬 Промпт - тест картинок
Что изображено на этой картинке?

Положи $5 на баланс Anthropic API

Это "пропуск" чтобы Claude Code вообще запустился. Деньги не спишутся - вся генерация идёт через твою локальную Ollama. Один раз положил - и кодишь бесплатно до конца жизни.

Открой console.anthropic.com
Войди в аккаунт (или зарегистрируйся)
Пополни баланс на $5 (Billing → Add credits)
Этого хватит навсегда - они лежат как верификация
💡 Важно: Это разовая инвестиция. $5 один раз - и кодишь бесплатно до конца жизни. Самая дешёвая инвестиция которую ты сделаешь в AI-инструменты за всё время.
07

Запусти Claude Code с Gemma 4

В терминале Antigravity одной командой запускаешь Claude Code с селектором моделей Ollama. Он покажет список доступных моделей - выбираешь Gemma 4.

⌨️ Команда - запуск Claude с селектором
ollama launch claude
Нажми Enter - появится интерактивный селектор моделей
Стрелками найди gemma4:e4b в списке
Нажми Enter для выбора модели
⚙️ Если требуется авторизация: Набери /logout → потом /login → выбери API usage billing (НЕ Max подписку!) → выбери свою организацию где лежат $5 → авторизуйся.
08

Финальный тест - Hello World локально

Даём локальной модели задачу создать HTML-файл. Это финальная проверка, что всё работает - ИИ-агент пишет код прямо на твоём ПК без единого байта в интернет.

💬 Промпт - создать HTML-файл
Создай в этой директории файл index.html. Сделай простую страницу с тёмным фоном и надписью 'Hello World' по центру экрана
Отправь промпт в Claude Code
Gemma 4 сгенерирует код - медленнее чем Opus 4.6, это нормально для локальной модели
Подтверди изменения (Accept)
Файл создан - теперь попросим его открыть
💬 Промпт - открыть файл
Отлично, а теперь открой этот файл для меня
✅ Результат: В браузере откроется index.html - тёмный фон, "Hello World" по центру. Полностью написано и запущено локально, без единого цента за API. Это Hello World для демонстрации, но принцип тот же - можешь попросить лендинг, калькулятор, бота, автоматизацию. Ограничение только у твоего воображения.
